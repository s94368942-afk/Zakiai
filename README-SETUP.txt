ZAKI AI mobile starter

Files:
- index.html: dashboard and demo chat/voice interface
- manifest.json: installable web app metadata
- sw.js: basic offline cache

IMPORTANT:
This is a starter/demo only. It does NOT contain a real AI model, image generator,
or video generator. Those require separate secure services and server-side setup.
Do not put passwords, OTPs, or private API keys in these files.

To add to your GitHub repository:
1. Extract this ZIP on your phone.
2. Open your repository in a browser and choose Add file > Upload files.
3. Select index.html, manifest.json, and sw.js together, then commit.
4. Hosting must use HTTPS for installation as an app.
